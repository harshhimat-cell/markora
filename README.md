# Markora

> Real intelligence. No noise.

Live financial news and markets platform covering equities, crypto, forex, commodities, fixed income, real estate, derivatives, ETFs and more.

## Live data sources (all free)
- **Crypto** — CoinGecko API
- **Forex** — ExchangeRate API  
- **News** — Reuters, Economic Times, Moneycontrol, CoinTelegraph, Mint RSS feeds
- **Equities** — NSE India public API
- **MFs** — AMFI India

## Deploy
Hosted on Cloudflare Pages. Push to main branch to auto-deploy.
